## Reproduction

The conversation archive already contains readable sources and full results.
The compact Git delivery bundles sources/inputs and short receipts. First run:

    python UNPACK_SOURCE.py
    python reproduce.py
    python replay.py

reproduce.py executes the7 deterministic invocations and regenerates all9
outputs. replay.py reruns them in a clean source-only directory. It compares
bytes when original outputs exist; otherwise it compares their recorded
SHA256 and size and explicitly distinguishes that in the receipt.

by rounding displayed ratios. No external service or math package is needed.

Both graph algorithms and the saved-row audit are included. The simple tree
DP and independent vertex deletion have separate polynomial multiplication.

is not a rerun of an entire earlier round. Exact integer/rational results are
authoritative; display decimals have no role in deciding inequalities.
