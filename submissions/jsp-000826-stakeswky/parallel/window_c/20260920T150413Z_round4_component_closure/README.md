# Window C, Round 4 — component closure and signed budgets

**ORIGINAL: NOT_CLOSED. C4-F: NOT_CLOSED.**

This package proves a restricted infinite-multiplicity component theorem, not
the unrestricted disconnected-forest conjecture. Read PROOF.md and the two
interfaces in CLAIMS_FOR_AB.md. The finite palette comprises the exact 26,
212, 226 and 239-vertex trees defined there. No unproved Window A conclusion
is used. No global novelty or formal verification is claimed.

## Results

1. Exact budget minus actual allocation variance is invariant under component
partition. Refinement increases both by the same amount. This identity does
not itself prove the budget is sufficient.
2. Every finite multiset of the four tree types is unimodal, as is its disjoint
union with an arbitrary LC whole-forest factor. An explicit induction uses
19 verified LC blockers and 27 residual non-LC but unimodal configurations.
This yields a true R_budget>=V comparison at every descent-history position.
In a vertex-minimal bad forest, even with arbitrary other components, the
19 blockers are forbidden; at most four palette components can occur.

## Reproduction

Python 3.11 or later, standard library only, without the -O flag:

```sh
python UNPACK_SOURCE.py
python verify_palette.py --out certificates
python verify_budgets.py --out certificates
python audit_certificate.py --out certificates
```

The first command verifies and unpacks the source/compact receipt bundle.
In the complete conversation archive those files are already present and
identical files are left unchanged. No inherited code bytes are claimed:
these graph counters and audit drivers were reconstructed in this run.
The expected fresh-output hashes are in REPLAY.json.

The three-way recount covers every coefficient of all 46 finite candidates,
not only their modes: 14,406 entries. The two graph algorithms are rooted
include/exclude DP and vertex deletion with component factorization. The
latter uses independent carry-free integer multiplication. Explicit hub-state
polynomials provide the third count. The 56 size-five combinations are
combinatorial completeness checks, not additional graph recounts.

The targeted budget audit has 19 real middle/history positions, including
nine with an earlier strict descent and 12 with negative local sigma mass.
One additional position lies at the range boundary and is a separate control.
All exact weights and negative local terms at B212+B226, k=137 and 138, are
saved. There are 51 quadratic kernel checks and literal residual-moment
checks on nine small forests (479 subsets, 34 supported size positions).
These diagnostic counts are not a proof for arbitrary component types.
