## B6-JC-ONE-v1: a NEW composite diagnostic network, not E5-ONE rebranding

At a fixed index j of an actual finite forest F, list ALL admissible groups
(C,D): C independent, C disjoint D, no C-D edges, 2|C|+|D|=2j.
The group signed surplus is the center-minus-preceding coefficient of
product_Q(z^a_Q+z^b_Q), with multiplicity two for balanced components.
Cancel positive/negative objects within each group once. Reserve E4's
canonical loads, Phase13 loads ONLY at global j=4, then the additional
E5-JC-v2 sources in its published order; never pay an overlapping source twice.
E5 release chooses the lexicographically first eligible four-set in the
ACTUAL full graph, retaining the published first-two ordering restriction.

The remaining negative groups are the left nodes; ALL positive groups with
unused capacity are right nodes. Include an arc exactly when
C_source subset C_target and |(C_target union D_target) minus
(C_source union D_source)|<=1. Capacity is the ACTUAL remaining integer surplus.
Test whether integral flow pays all remaining demands. A negative cut must
include the COMPLETE neighborhood under THIS permission and reservation list.

This composition is a B diagnostic. E's early E5-ONE-v1 reserves only E4 and
Phase13 and is tested SEPARATELY with those exact reservations. The four-point
release of E5-JC-v2 is not a C-increasing one-new-vertex operation. Its source
and target ledgers are not silently called E5-ONE edges.

Positive flow on an allowed subnetwork certifies the corresponding full
network only for the sources whose full demand is listed. A frozen core
fiber is not all negative groups of the ambient forest. A restricted negative
cut cannot refute a larger network or ORIGINAL. A capacity counterexample
must also separately state HEREDITARY, middle/history and complete sequence.
