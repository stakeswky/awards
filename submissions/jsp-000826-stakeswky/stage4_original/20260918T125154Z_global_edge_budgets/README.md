# Global edge budgets run

ORIGINAL: **NOT_CLOSED / NO_STRUCTURAL_ADVANCE**. Start with STATEMENT.md, then PROOF_ATTEMPT.md, GAP.md, REVIEW.md and VERDICT.json.

All code uses Python's standard library. From this run directory:

```sh
python -S -B src/check.py --out certificates
python -S -B src/search.py --out certificates
python -S -B src/compact.py --out certificates
python -S -B src/clean_replay.py
```

The Git-hosted native certificates are `certificates/MATERIAL_GRAPHS.json` (every material graph's complete edge set and full P) and `certificates/RATIO_WITNESS.json` (the eleven-vertex ratio witness's full A/B and edge arrays). This is readable integer data, not only hashes.

The delivery archive additionally contains all raw A/B/C/H/Z/edge-deletion/contraction arrays for all eleven material records, and a lossless full polynomial table. The three commands above regenerate these same complete arrays from the Git-hosted native source. In the archive's material_compact.json, each object containing only polynomial_id refers to the exact zero-padded array at that index of polynomials. compact.py roundtrips all source JSON. EVIDENCE.json and CLEAN_REPLAY.json record the actual full-byte comparisons.

A compressed-text upload failed its byte-identity check and was rejected before any branch update. No unverified fragment is referenced in this Git package; see provenance/REJECTED_TRANSPORT.json. The unchanged complete raw data and compressed representation remain in the delivery archive.
