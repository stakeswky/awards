## Family proof outline

Start with an edge r--h. Attach t branch vertices to h, attach three vertices to each branch, then five leaves to each of those vertices. Thus n=19t+2. Define

```
S=(1+x)^5+x
Q=S^3
R=(1+x)^15
H=Q+xR
P_t=(1+x)H^t+xQ^t
```

The maximum independent set has size 16t+1 and is unique. The v2 proof verifies ordered log-concavity of the fixed bases, coefficientwise 4R>=3Q and Q'<=18Q, then uses convolution closure for the factorial-weighted coefficient sequences.

For a=H^t and b=xQ^t the coefficient bound is

```
a_k >= L_t(k) b_k
L_t(k) = 3t/4 + (k-1)(t-1)/64
         + (k-1)(k-2)(t-1)(t-2)/(4608t).
```

Two exact bivariate polynomial expansions establish the required bounds for t>=70. Each translated certificate has 25 strictly positive coefficients. Every remaining integer t=1,...,69 is checked exactly. The combination is a computer-assisted written proof, not inference from finitely many successful tests.

The archive records 38,778 original-graph coefficients and 138 independently rebuilt vertex splits, containing 152,628 split coefficients. These are verification counts, not new counterexample searches.

```

```
